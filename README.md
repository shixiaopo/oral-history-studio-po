# 人生之书 · 口述历史工作室（oral-history-studio）

> 把爸妈、爷爷奶奶的一生，一点点聊成一本可以传给后代的书。

![license](https://img.shields.io/badge/license-MIT-green) ![version](https://img.shields.io/badge/version-2.5.2-blue)

**人生之书**是一套完整的口述历史工作流：AI 帮你出采访问题清单当抓手 → 长辈用豆包语音聊天或你当面录音 → AI 把口语转写稿整理成第一人称人生文稿 → 自动核对前后矛盾 → 攒够了一键合订成书。

已在真实 2.5 小时采访录音上验证全链路。

是的——**README 的作用就是让你在这里完成决策**，想清楚要哪条路，只拿需要的文件：

两条路可以都走：平时用豆包让长辈随时聊（B），素材攒够后在 Agent 里整理成书（A）。选错了也没关系——文件都是同一套，随时补装。

## 用法 A：完整人生之书工作流（自己采访，AI 当秘书）

**只有当你决定「亲自采访长辈、让 AI 做幕后」时，才需要装 skill**——在 WorkBuddy / Claude / GPT / MiniMax Agent 这些平台上创建一个能调用本 skill 的智能体（各平台装法不同，共同点是都能让 AI 读到文件）。装好后的定位：**AI 是你的秘书**，它出问题清单、整理文稿、核对事实、成书；采访现场的提问和追问由你本人掌握。

### 最懒的装法：让 Agent 自己来 GitHub 拿

不想手动下载、创建智能体？**直接把你面前这个 Agent 当跑腿的**——对 WorkBuddy / Claude Code / Cursor 等能联网、能读文件的 Agent 说：

> 「帮我从 GitHub 克隆 https://github.com/shixiaopo/oral-history-studio-po 这个口述历史 skill，读一下它的 SKILL.md，然后我要给我爸做一本人生之书」

Agent 会自己 clone 仓库、读懂 SKILL.md、按里面的工作流开工。README 你都不用看——SKILL.md 的「环境路由」会让它自动进入加工端模式。

> 兼容性说明：本 skill 的核心（SKILL.md + 两个 references 方法论）是纯提示词资产，任何能读文件的 AI 都能直接执行；`scripts/oh_cli.py` 是可选的持久化工具，没有它流程照样能跑（AI 直接按方法论出清单、整理文稿即可）。

### scripts/oh_cli.py 配置说明

`oh_cli.py` 是加工端的命令行工具（转写、整理、台账、成书），依赖 AI 接口。**Key 不写死在代码里**，通过环境变量或配置文件提供：

```bash
# 方式一：环境变量
export OH_API_KEY="你的 API Key"
export OH_BASE_URL="https://open.bigmodel.cn/api/paas/v4"   # 可选，默认智谱
export OH_MODEL="glm-5.3-flash"                              # 可选

# 方式二：写入 ~/.ohrc.json
python3 scripts/oh_cli.py config --key xxxx --model glm-5.3-flash

# 随时查看当前生效配置（Key 打码显示）
python3 scripts/oh_cli.py config
```

- 文本模型只需 OpenAI 兼容接口（智谱 GLM / DeepSeek / Kimi / 通义均可）；转写需支持 Whisper 协议的 ASR（默认 glm-4-asr）
- 你的宿主 Agent 自带模型时可以完全不配 Key：脚本只管存取与流程，AI 步骤由宿主模型按 references 里的提示词直接执行
- 语音支持 MP3/M4A/WAV；超大录音自动压缩、切段转写再拼接

## 用法 B：AI 替你采访长辈（豆包 / MiniMax 等语音产品）

`assets/doubao-collector.md` 是一份自包含的代访提示词——**它就是全部，没有"安装"这个概念，粘贴进对话就能用**。它内置：

- **人生全景题库**：九大地带 61 道具体锚点题（小时候 / 原生家庭 / 求学 / 工作 / 成家 / 育儿与子女 / 里程碑事件 / 里程碑人物 / 晚年回望），AI 永远有下一道题，不会在一个话题里绕圈子
- **双模式采访**：长辈停下来就推进主线（拿下一道题），长辈开讲就放下主线追问细节（5W1H 补缺口）
- **防黏着三禁**：同一元素最多带 1 次 / 禁连续"是不是"猜测式提问 / 收束后必须拿新题
- **保护铁律**：说记不清就放过、累就收、情绪上来先陪伴
- **自动存档**：约 20 分钟/15 轮/4–6 话题后自动产出逐字稿 + 代访记录

### 怎么用（就一步）

豆包/MiniMax 新建对话 → 全文复制粘贴 `assets/doubao-collector.md` → 附一句「请严格按照以上设定执行，我家人要做人生之书」→ 点对话页电话图标进语音通话 → 把手机递给长辈就能聊。

> 想长期反复用：把全文贴进你所用平台的智能体设定框里即可，省去每次粘贴。不弄这一步也完全能用。

### 素材怎么变成书

长辈聊完后，豆包对话里会留下逐字稿和代访记录。复制发给你（微信即可），然后走用法 A 的整理流程：「整理这段采访」+ 粘贴素材。一条链路就通了：

```
长辈对着豆包/MiniMax聊 ──逐字稿──▶ 微信发给你 ──▶ 你的Agent整理成文稿 ──▶ 攒够了一键成书
```

## 三条整理铁律（文稿质量的保证）

1. **平实**——不文艺腔、不拔高情感。长辈说"穷得叮当响"，就写"穷得叮当响"。
2. **不编造**——文稿里每个时间、地点、人名、事件都必须是长辈说过的。没说的一个字不加。
3. **第一人称"我"**——全篇以长辈的口吻讲述，提问全部隐去。

## 快速开始（两条路，选一条）

**路 1（最简单）：让 AI 替你采访长辈**

1. 把 `assets/doubao-collector.md` 全文粘贴进豆包对话（附一句「请严格按照以上设定执行，我家人要做人生之书」）
2. 点电话图标进语音通话，把手机递给长辈

3. 录音丢进 WorkBuddy，说「整理一下」→ 收到第一篇人生文稿
4. 满意了继续约下一次；素材够了说「导出成书」

## 常见问题

**Q：我爸妈不会用这些 AI 工具，怎么办？**
A：他们不需要"会用"。长辈只需要对着豆包/MiniMax 说话——把手机递给他就行（用法 B）。整理成书永远是你（发起人）在自己熟悉的工具里操作。

**Q：AI 会不会在长辈讲一件事的时候绕圈子？**
A：这正是本题库设计的核心。九大地带 61 道题保证 AI 手里永远有下一道题；5W1H 完成度判断（六面问够 4 面即收束）+ 防黏着三禁（同一元素最多带一次/禁猜测式提问/收束必拿新题），从规则上杜绝"枣树上绕来绕去"。

**Q：长辈方言重、表达碎，整理出来能看吗？**
A：能。方言词原样保留（这是珍贵语料），口头禅和卡顿会删掉；所有内容按主题重组，读起来是流畅的第一人称讲述。

**Q：几次采访之间 AI 记得住吗？**
A：记得住。每次整理时更新"事实台账"，跨次矛盾自动检测并提醒核实。

**Q：录音很大怎么办？**
A：直接丢。超 90MB 自动压缩，压完还超限自动切段转写再拼接，全程无感。

**Q：隐私呢？**
A：所有内容只存在你自己的工作目录；豆包端遵守对应平台隐私规则。建议素材经你自己的微信/网盘传递。API Key 只存你本机（环境变量或 `~/.ohrc.json`），不进代码、不进仓库。
