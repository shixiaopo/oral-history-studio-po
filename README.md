# 人生之书 · 口述历史工作室（oral-history-studio）

> 把爸妈、爷爷奶奶的一生，一点点聊成一本可以传给后代的书。

![license](https://img.shields.io/badge/license-MIT-green) ![version](https://img.shields.io/badge/version-2.2.0-blue)

**人生之书**是一套完整的口述历史工作流：AI 帮你出采访问题清单当抓手 → 长辈用豆包语音聊天或你当面录音 → AI 把口语转写稿整理成第一人称人生文稿 → 自动核对前后矛盾 → 攒够了一键合订成书。

已在真实 2.5 小时采访录音上验证全链路。

## 三种使用方式（按需选一种）

| 方式 | 适合谁 | 需要什么 |
|------|--------|----------|
| **① 豆包直装 zip 技能**（最推荐） | 有电脑的家人，想一键装好 | 豆包 PC 版，拖入 `dist/oral-history-studio.zip` 即可 |
| **② 豆包贴提示词**（零门槛） | 给爸妈/长辈用，手机就能操作 | 复制 `assets/doubao-collector.md` 全文，粘贴到豆包新对话 |
| **③ WorkBuddy 安装 Skill** | 想要完整整理/成书链路的你 | WorkBuddy，装入本仓库（即本 skill 完整包） |

### 方式① 豆包直装（PC 版）

1. 打开豆包 PC 版 → 左侧「技能·连接器·伙伴」→「技能」
2. 右上角「+ 新建」→「上传技能」
3. 把 `dist/oral-history-studio.zip` **直接拖进去**（不用解压），约 1 分钟装好

> 懒人装法：把 zip 发到豆包对话里，说「帮我创建技能」，它自己下载安装。

### 方式② 贴提示词（长辈手机可操作）

打开豆包新建对话 → 全文复制粘贴 `assets/doubao-collector.md` → 附一句「请严格按照以上设定执行，我家人要做人生之书」→ 点右上角电话图标进语音通话 → 把手机递给长辈就能聊。

### 方式③ WorkBuddy Skill

WorkBuddy 对话里说：

> 「我要给我爸做一本人生之书」

即自动激活本 skill 的完整工作流（采访清单 → 录音转写 → 整理成文稿 → 成书）。

## 它是怎么工作的

这个产品是一条**家庭协作链路**，由两端组成：

| | 谁用 | 用什么 | 干什么 |
|---|---|---|---|
| **采集端（家庭端）** | 长辈 + 陪伴的长辈家人 | **豆包**（爸妈手机上基本都有） | 长辈对着它语音聊天，故事被聊出来、记下来 |
| **加工端（你）** | 发起这本书的子女 | **WorkBuddy + 本 Skill** | 出采访清单、整理文稿、跨次核对事实、合订成书 |

一句话分工：**豆包负责"聊"，本 Skill 负责"写"。**

```
长辈对着豆包聊 ──逐字稿──▶ 微信发给你 ──▶ WorkBuddy 整理成文稿 ──▶ 攒够了一键成书
```

## 你能得到什么

| 环节 | 产出 |
|------|------|
| 采访前 | 一份 8-12 个问题的采访清单（含追问提示），打印了就能用 |
| 采访后 | 第一人称人生文稿——像长辈亲口在给儿孙讲自己的一生 |
| 自动核对 | 前后说法有出入（结婚年份、地名……）自动标出来提醒你核实 |
| 循环推进 | 每次整理完自动生成下一轮问题清单，接着上次深挖 |
| 成书 | 所有文稿一键合订，可转 docx/PDF 排版 |

## 三条整理铁律（文稿质量的保证）

1. **平实**——不文艺腔、不拔高情感。长辈说"穷得叮当响"，就写"穷得叮当响"。
2. **不编造**——文稿里每个时间、地点、人名、事件都必须是长辈说过的。没说的一个字不加。
3. **第一人称"我"**——全篇以长辈的口吻讲述，提问全部隐去。

## 快速开始（本页最小可用路径）

1. 在 WorkBuddy 里说「我要给我爸做一本人生之书」→ 拿到问题清单
2. 和长辈聊一次，录音
3. 录音丢进 WorkBuddy，说「整理一下」→ 收到第一篇人生文稿
4. 满意了继续约下一次；素材够了说「导出成书」

## scripts/oh_cli.py 配置说明

`oh_cli.py` 是加工端的命令行工具（转写、整理、台账、成书），依赖 AI 接口。**Key 不写死在代码里**，通过环境变量或配置文件提供：

```bash
# 方式一：环境变量
export OH_API_KEY="你的 API Key"
export OH_BASE_URL="https://open.bigmodel.cn/api/paas/v4"   # 可选，默认智谱
export OH_MODEL="glm-5.3-flash"                              # 可选

# 方式二：写入 ~/.ohrc.json
python3 scripts/oh_cli.py config --key xxxx --model glm-5.3-flash

# 随时查看当前生效配置（Key 打码显示）
python3 scripts/oh_cli.py config
```

语音转写默认用 `glm-4-asr`，支持 MP3/M4A/WAV；超大录音自动压缩、切段转写再拼接。

## 常见问题

**Q：我爸妈不会用 WorkBuddy，怎么办？**
A：他们不需要用。长辈只用豆包聊天（几乎零门槛），或你按方式②直接把提示词贴进豆包。WorkBuddy 这端永远是你（发起人）在操作。

**Q：豆包里怎么装这个技能？**
A：豆包 PC 版 →「技能·连接器·伙伴」→「技能」→ 右上角「+ 新建」→「上传技能」→ 拖入 `dist/oral-history-studio.zip`（不用解压）。手机 App 端技能体系不同，长辈手机上推荐方式②贴提示词。

**Q：长辈方言重、表达碎，整理出来能看吗？**
A：能。方言词原样保留（这是珍贵语料），口头禅和卡顿会删掉；所有内容按主题重组，读起来是流畅的第一人称讲述。

**Q：几次采访之间 AI 记得住吗？**
A：记得住。每次整理时更新"事实台账"，跨次矛盾自动检测并提醒核实。

**Q：录音很大怎么办？**
A：直接丢。超 90MB 自动压缩，压完还超限自动切段转写再拼接，全程无感。

**Q：隐私呢？**
A：所有内容只存在你自己的工作目录；豆包端遵守豆包平台隐私规则。建议素材经你自己的微信/网盘传递。API Key 只存你本机（环境变量或 `~/.ohrc.json`），不进代码、不进仓库。
