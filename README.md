# 人生之书 · 口述历史工作室（oral-history-studio）

> 把爸妈、爷爷奶奶的一生，一点点聊成一本可以传给后代的书。

![license](https://img.shields.io/badge/license-MIT-green) ![version](https://img.shields.io/badge/version-2.3.0-blue)

**人生之书**是一套完整的口述历史工作流：AI 帮你出采访问题清单当抓手 → 长辈用豆包语音聊天或你当面录音 → AI 把口语转写稿整理成第一人称人生文稿 → 自动核对前后矛盾 → 攒够了一键合订成书。

已在真实 2.5 小时采访录音上验证全链路。

---

## 两种用法（按你的角色选）

| | 用法 A：完整人生之书工作流 | 用法 B：纯代访采访 AI |
|---|---|---|
| **你是谁** | 发起人：亲自操盘整个流程 | 甩手掌柜：只想要一个会采访长辈的 AI |
| **AI 干什么** | 当你的**秘书**：出清单 → 整理文稿 → 核对事实 → 成书（循环推进） | 化身孙辈，直接跟长辈语音聊天把故事问出来 |
| **谁在采访** | **你本人**拿着清单去采访长辈（AI 不在场） | **AI 本人**跟长辈语音聊（你不用出面） |
| **现场可控性** | 现场你问啥、追啥，AI 管不到——没关系，聊回来的素材（录音/转写稿）进整理环节后，AI 会把该挖的挖出来、该核的核出来 | AI 按题库和防黏着规则自己推进，质量和一致性靠提示词保证 |
| **装在哪** | WorkBuddy / Claude / GPT / 任意能读文件的 Agent | 豆包 / MiniMax 等带实时语音的多模态大模型产品 |
| **包内对应** | 本仓库全部（SKILL.md + references/ + scripts/） | `assets/doubao-collector.md` 一个文件 |
| **适合场景** | 你想深度参与、攒一本完整的书 | 你不在长辈身边，或只想快速把故事录下来 |

两种用法可并存：平时用 B 让长辈随时聊，素材攒够后用 A 整理成书。

## 用法 A：完整人生之书工作流（平台无关）

本仓库就是一个标准 Agent Skill 包（`SKILL.md` + 方法论 + 命令行工具）。**装进任何支持 Skill/文件上下文的 Agent 产品都能用**（WorkBuddy、Claude、GPT、MiniMax Agent 等，装法各有不同，但共同点是——都能让 AI 读到文件）。装好后的定位：**AI 是你的秘书**，它出问题清单、整理文稿、核对事实、成书；采访现场的提问和追问由你本人掌握。

### WorkBuddy（推荐，一键装）

WorkBuddy 对话里说：

> 「我要给我爸做一本人生之书」

即自动激活完整工作流。

### Claude / GPT / 其他 Agent

1. 把本仓库内容（至少 `SKILL.md` + `references/` 两个文件）放进你的 Agent 上下文：
   - Claude Projects：把 `SKILL.md`、`references/question-methodology.md`、`references/manuscript-prompt.md` 上传为项目知识
   - GPTs：把同样内容贴进 Instructions 或知识文件
   - 命令行 Agent（Claude Code 等）：直接 clone 本仓库，让 Agent 读 SKILL.md 照做
2. 对 AI 说：「我要给我爸做一本人生之书」——后续流程完全一致

### 核心循环

```
①开书 → ②AI出问题清单 → ③你线下采访/长辈聊天（录音）
              ↑                              │ 录音或转写稿
              │                              ▼
      ⑥AI备下一轮清单 ← ⑤AI整理文稿+跨次核对 ← ④转写（自动/AI）
                                        ↓
                                  素材够了 → export 成书
```

### scripts/oh_cli.py 配置说明

`oh_cli.py` 是加工端的命令行工具（转写、整理、台账、成书），依赖 AI 接口。**Key 不写死在代码里**，通过环境变量或配置文件提供：

```bash
# 方式一：环境变量
export OH_API_KEY="你的 API Key"
export OH_BASE_URL="https://open.bigmodel.cn/api/paas/v4"   # 可选，默认智谱
export OH_MODEL="glm-5.3-flash"                              # 可选

# 方式二：写入 ~/.ohrc.json
python3 scripts/oh_cli.py config --key xxxx --model glm-5.3-flash

# 随时查看当前生效配置（Key 打码显示）
python3 scripts/oh_cli.py config
```

- 文本模型只需 OpenAI 兼容接口（智谱 GLM / DeepSeek / Kimi / 通义均可）；转写需支持 Whisper 协议的 ASR（默认 glm-4-asr）
- 你的宿主 Agent 自带模型时可以完全不配 Key：脚本只管存取与流程，AI 步骤由宿主模型按 references 里的提示词直接执行
- 语音支持 MP3/M4A/WAV；超大录音自动压缩、切段转写再拼接

## 用法 B：纯代访采访 AI（豆包 / MiniMax 等语音产品）

`assets/doubao-collector.md` 是一份自包含的代访提示词——**粘贴进任何带实时语音的 AI 对话/智能体，它就变成会采访长辈的"孙辈"**。用法 A 和用法 B 的本质区别：A 里 AI 是幕后的秘书（你采访），B 里 AI 是台前的采访者（长辈对 AI 聊）。它内置：

- **人生全景题库**：九大地带 61 道具体锚点题（小时候 / 原生家庭 / 求学 / 工作 / 成家 / 育儿与子女 / 里程碑事件 / 里程碑人物 / 晚年回望），AI 永远有下一道题，不会在一个话题里绕圈子
- **双模式采访**：长辈停下来就推进主线（拿下一道题），长辈开讲就放下主线追问细节（5W1H 补缺口）
- **防黏着三禁**：同一元素最多带 1 次 / 禁连续"是不是"猜测式提问 / 收束后必须拿新题
- **保护铁律**：说记不清就放过、累就收、情绪上来先陪伴
- **自动存档**：约 20 分钟/15 轮/4–6 话题后自动产出逐字稿 + 代访记录

### 安装（两种方式任选）

**① 贴提示词（零门槛，任何语音 AI 产品都行，长辈手机可操作）**

豆包/MiniMax 新建对话 → 全文复制粘贴 `assets/doubao-collector.md` → 附一句「请严格按照以上设定执行，我家人要做人生之书」→ 点对话页电话图标进语音通话 → 把手机递给长辈就能聊。

**② 创建智能体/技能（想长期用就选这个）**

WorkBuddy、豆包、MiniMax 这类平台都支持创建智能体（豆包 PC 版还能直接上传 `dist/oral-history-studio.zip` 装成技能），入口名称各不相同，但共同点是——都能粘贴一段设定文字。把 `assets/doubao-collector.md` 全文贴进设定描述即可，还能分享给家人。

### 素材怎么变成书

长辈聊完后，豆包对话里会留下逐字稿和代访记录。复制发给你（微信即可），然后走用法 A 的整理流程：「整理这段采访」+ 粘贴素材。一条链路就通了：

```
长辈对着豆包/MiniMax聊 ──逐字稿──▶ 微信发给你 ──▶ 你的Agent整理成文稿 ──▶ 攒够了一键成书
```

## 三条整理铁律（文稿质量的保证）

1. **平实**——不文艺腔、不拔高情感。长辈说"穷得叮当响"，就写"穷得叮当响"。
2. **不编造**——文稿里每个时间、地点、人名、事件都必须是长辈说过的。没说的一个字不加。
3. **第一人称"我"**——全篇以长辈的口吻讲述，提问全部隐去。

## 快速开始（本页最小可用路径）

1. 在 WorkBuddy 里说「我要给我爸做一本人生之书」→ 拿到问题清单
2. 和长辈聊一次，录音
3. 录音丢进 WorkBuddy，说「整理一下」→ 收到第一篇人生文稿
4. 满意了继续约下一次；素材够了说「导出成书」

## 常见问题

**Q：我爸妈不会用这些 AI 工具，怎么办？**
A：他们不需要"会用"。长辈只需要对着豆包/MiniMax 说话——把手机递给他就行（用法 B）。整理成书永远是你（发起人）在自己熟悉的工具里操作。

**Q：AI 会不会在长辈讲一件事的时候绕圈子？**
A：这正是本题库设计的核心。九大地带 61 道题保证 AI 手里永远有下一道题；5W1H 完成度判断（六面问够 4 面即收束）+ 防黏着三禁（同一元素最多带一次/禁猜测式提问/收束必拿新题），从规则上杜绝"枣树上绕来绕去"。

**Q：长辈方言重、表达碎，整理出来能看吗？**
A：能。方言词原样保留（这是珍贵语料），口头禅和卡顿会删掉；所有内容按主题重组，读起来是流畅的第一人称讲述。

**Q：几次采访之间 AI 记得住吗？**
A：记得住。每次整理时更新"事实台账"，跨次矛盾自动检测并提醒核实。

**Q：录音很大怎么办？**
A：直接丢。超 90MB 自动压缩，压完还超限自动切段转写再拼接，全程无感。

**Q：隐私呢？**
A：所有内容只存在你自己的工作目录；豆包端遵守对应平台隐私规则。建议素材经你自己的微信/网盘传递。API Key 只存你本机（环境变量或 `~/.ohrc.json`），不进代码、不进仓库。
