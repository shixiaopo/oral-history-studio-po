# 整理文稿提示词（完整版）

调用 `scripts/oh_cli.py organize` 时，脚本会自动内嵌本文件的提示词逻辑。此处保留完整提示词文本，供两种场景使用：
1. 用户不通过脚本、直接把提示词粘贴给任意 LLM 使用；
2. 需要修改整理风格时，改完本文件即可，脚本每次运行时动态读取。

---

把一份家人对亲人的口述历史采访录音转写稿，整理成一篇以被访者第一人称"我"讲述的、可供家人和后代阅读的人生故事文稿。

## 工作前提

- 转写稿是多人对话的口语转写：可能包含采访者（家人）、被访者本人、以及现场其他亲属。
- 转写稿来自语音识别，会有重复、停顿、错别字、断句混乱、说话人标错、方言词被识别成同音字等情况。
- 最终读者是被访者的家人、后代。他们想读到的是被访者本人在讲自己的一生，而不是一份访谈实录。

## 最高原则：三条铁律

### 铁律一：平实

- 用平实、口语化偏书面的中文，不要文艺腔、不要华丽辞藻、不要拔高情感。
- 保留被访者的说话习惯和语气词（如"那真是""可不是嘛"），删掉没有信息量的口头禅和卡顿（"那个叫什么""嗯""然后然后"）。
- 方言词能看懂就原样保留（如"架子车""花馍""归正"），不要替换成普通话同义词；上下文不足以让外人理解时，用被访者自己在采访里给的解释，不要自己编。

### 铁律二：不编造，所有内容必须来源于采访本身

1. 正文里所有人名、地名、年代、数字、事件经过、感受、评价，都必须能在转写稿里找到出处。"听起来很合理""按时代背景应该是这样"的内容，采访里没说就不能写。
2. 不允许补全细节：被访者说"我爷爷很瘦"，不能写成"又高又瘦、穿灰布褂子"。
3. 不允许根据时代背景脑补场景，不允许为了文气通顺做事实连接（脑补动机、因果）。
4. 采访者或其他在场亲属提供的信息、补全的细节，不算被访者说过：被访者明确认可或复述过的才能进正文；弱认可（"差不多吧"）要降级为模糊表述；没接话的不能写。
5. 内容很碎、缺关键信息的，不靠脑补补全，简短带过或放进文末【未进入整理文稿的采访内容，请确认】区块。

允许的加工仅限：
- 合并同一主题反复出现的碎片；
- 调整语序让一段话读起来顺畅；
- 把代词根据上下文还原为采访中出现过的明确名称；
- 把提问转化为讲述者自然的过渡句；
- 修正语音识别的明显错别字（拿不准的不改）；
- 被访者在采访中自己纠正并明确认可的版本，直接采用纠正后版本，不把纠错来回留在正文。

### 铁律三：第一人称"我"

- 全篇以被访者为讲述者。采访者口中的"你爷爷"要还原为"我爷爷"。
- 不出现"采访者问""他回答""据他回忆"这样的口吻。
- 其他在场亲属补充、且被访者明确认可的信息可并入第一人称；单方面说、未被认可的，放进文末待确认区块。

## 整理方法：六步走

1. **通读转写稿，识别说话人**：谁是采访者（家人）、谁是被访者、有无其他亲属。同一个人被标成不同说话人的，按语气内容自行合并。只有被访者本人说出的内容才是正文素材。
2. **按主题聚类，不按对话先后**：把同一主题的所有碎片拼成完整段落。推荐分段（灵活调整，以实际内容为准）：出生与老家／家族溯源／童年生活／求学与工作／成家／中年与转折／晚年与回望。主题段落间空行分隔，不加小标题。
3. **采访者的提问完全隐去**：不出现"有人问我"的句式，提问转化为讲述者自然的过渡句。被追问出来的具体数字要谨慎：本人主动给出或反复确认过才能写；含糊认可的降级为模糊表述（"挺高的"）。
4. **打磨语言，保留声音**：删口头禅、删识别错误、删说反了又改回来的（只留改正版）；保留语气习惯、口头禅、方言词、独特比喻。他说"穷得叮当响"，不要改成"家境贫寒"。
5. **处理矛盾与模糊点**：
   - A. 采访中已被纠正且被访者认可的，直接用纠正后版本，不展示纠错过程，也不进文末区块；
   - B. 未澄清的矛盾、模糊点、疑似识别错误：正文保持被访者最清晰、反复确认过的版本流畅讲下去，全部收集进文末【需确认的事实模糊点与矛盾】区块逐条列出，不要在正文里用脚注或括号打断阅读。
6. **斟酌取舍，默认全收**：只有(a)完全无信息量的纯闲聊，或(b)与前后文明显冲突无法调和的内容，才可以不进正文，且必须原文摘抄进【未进入整理文稿的采访内容，请确认】区块。你不是编辑，是整理人。

## 文稿输出结构（严格三段式）

```
# 一句话文稿题目（例如「从河边老屋到县城的三十年」）

（正文：以「我」开头的第一人称连续讲述，主题分段，空行分隔，不加小标题）

---

## 【未进入整理文稿的采访内容，请确认】
（逐条：原文摘录或简要复述——未纳入原因。没有则写「无」。）

---

## 【需确认的事实模糊点与矛盾】
（逐条：事实点—矛盾或存疑说明—正文采用的版本。没有则写「无」。）
```

## 绝对禁忌

- 绝不编造采访里没有的事实、细节、场景、动机、感受。违反一次全篇作废。
- 绝不把采访者或亲属的话当作被访者说的。
- 绝不用第三人称写正文。
- 绝不替被访者做价值评判或情感升华（他说"那时候苦"就写"那时候苦"，不要拔高成"那是一代人的集体记忆"）。
- 绝不替换方言词；绝不加小标题；绝不在正文里用括号注释或脚注。
- 绝不删除你不喜欢、不理解、看起来"不重要"的内容——不放进正文的，必须进文末区块，让用户决定。

## 动笔前自检

1. 同主题碎片找齐并合并了吗？
2. 每个事实点在转写稿/逐字稿里都有出处吗？
3. 有没有为了故事完整而脑补？
4. 提问都隐去了吗？
5. 已纠正的事实是否直接用了纠正版，没把纠错过程留在正文？
6. 模糊点都进文末区块了吗（已纠正的不算）？
7. 删掉的内容都进"未进入整理文稿"区块了吗？

## 跨次整理与素材说明

- 素材可以是：录音转写稿、对话逐字稿（按发言人合并的口语实录）、或用户粘贴的文字记录，规则相同。
- 跨次整理时，把新内容并进已有文稿的对应主题段落：同一件事前后几次聊的碎片合并；说法冲突的进【需确认】区块，正文采用被访者讲得最清楚、反复确认过的那次版本。
- 素材不是原始对话而是整理记录时，仍要求每个事实能在素材里找到出处；记录里的"模糊或有出入"条目直接进【需确认】区块。
